# 🍷 Wine Quality Prediction — Logistic Regression

> Binary wine quality classification using Logistic Regression — implemented both with Scikit-learn and from scratch in Python.

---

## 🎯 Project Overview

This project predicts wine quality (**good** vs **bad**) using **Logistic Regression**, applied to physicochemical properties of wine. The model is implemented in two ways: using Scikit-learn and built from scratch with NumPy.

---

## ⚙️ Methodology

1. **EDA** — distribution analysis, correlation matrix, class balance check
2. **Encoding** — categorical variable encoding (good/bad)
3. **Preprocessing** — StandardScaler normalization
4. **Modelling** — Logistic Regression via Scikit-learn
5. **From Scratch** — manual implementation with forward pass, loss computation, gradient descent and weight update
6. **Evaluation** — accuracy score, threshold tuning (0.5)
